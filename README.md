# AI DJ Agent

**Pillar:** Business
**Status:** Kickoff
**Started:** 2026-03-16

## What

An AI agent that takes a natural language description of a setting (e.g., "house party for people who enjoy RnB and jazz") and generates a full DJ experience — not just a playlist, but intelligent song ordering, mixing, BPM matching, transitions, and flow management.

## The Problem

- Playlist generators (Spotify, Apple Music) pick songs but don't DJ
- Real DJing is about flow: reading the room, building energy, smooth transitions, BPM matching
- Hiring a DJ is expensive for casual events; auto-playlists feel flat
- No product currently bridges this gap

## How It Works (High-Level)

1. **Context understanding** — Parse natural language scene description (vibe, genre, audience, energy arc)
2. **Track selection agent** — Curate tracks based on genre, mood, energy, BPM compatibility
3. **Set planning** — Order tracks for optimal flow (energy curves, key matching, genre blending)
4. **Mix engine** — Handle transitions, crossfades, BPM alignment, beat matching
5. **Adaptive playback** — Optionally adjust in real-time based on feedback

## Revenue Model

- Freemium SaaS — free basic playlists, paid for mixing/transitions/export
- Event packages — one-time generation for parties/events
- B2B — bars, restaurants, small venues

## Target

- MVP in 2-4 weeks
- Validate with real users quickly
